# Implementação Algoritimo do Caminho Hamiltoniano

Este é um projeto de implementação em Python do Algoritmo do Caminho Hamiltoniano para a matéria de Fundamentos de Projeto e Análise de Algoritmos

## O Problema

Implementar um algoritmo que identifique um caminho que passe por todos os vértices de um grafo sem que haja repetições.

### Como executar

Este código não possuí dependências, basta rodar o script da seguinte maneira:

```
python main.py
```
